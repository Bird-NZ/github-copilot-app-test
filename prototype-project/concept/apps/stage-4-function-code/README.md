# Stage 4: Function Code Deployment

This stage deploys the Python function application code to the Azure Function App created in Stage 3.

## Prerequisites

- **Azure CLI**: Install from https://docs.microsoft.com/en-us/cli/azure/install-azure-cli
- **Azure Functions Core Tools v4**: Install from https://docs.microsoft.com/en-us/azure/azure-functions/functions-run-local
- **Python 3.12**: Runtime version matching the function app configuration
- **Stage 3 Completed**: Function App infrastructure must be deployed
