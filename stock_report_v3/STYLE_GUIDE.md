# Stock Report v3 — Style Guide

## Color palette
- Navy (header): `#0B1F3A`
- Indigo (section header): `#123A63`
- Accent blue: `#1F77B4`
- Accent green: `#2E8B57`
- Accent amber: `#D4A017`
- Accent red: `#B22222`
- Background: `#F4F7FB`
- Card white: `#FFFFFF`
- Border: `#D7DEE8`
- Text primary: `#111827`
- Text secondary: `#4B5563`

## Typography
- Title: bold, 28–34 px equivalent
- Section title: semibold, 16–20 px
- Table header: semibold, high contrast white on navy
- Body text: 10–12 px equivalent
- Footnotes: 8–9 px equivalent

## Layout principles
- A4 landscape ratio
- Clear 12-column feel with consistent gutters
- Keep data-dense region centered
- Avoid cramped text; wrap before truncating
- Maintain visual rhythm: header -> cards -> table/charts -> footer

## Tables
- Zebra row striping
- Right-align numeric columns where practical
- Fixed widths for score columns
- Color class text:
  - Good: green
  - Average: amber
  - Poor: red

## Charts
- Light grid (`alpha ~0.2`)
- Consistent line widths and axis labels
- Avoid overlapping legends with key data
- Keep chart titles explicit and short

## Data integrity display
- Show `N/A` explicitly for unavailable metrics
- Never silently fill unknowns
- Footnote data freshness and baseline refresh date every page
