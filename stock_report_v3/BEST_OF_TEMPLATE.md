# Stock Report v3 — Best-of Template

## Page 1 — Investment Snapshot (Decision Page)
**Purpose:** one-screen decision context.

### Header block
- Ticker + company name + market flag (US/AU/NZ)
- Last price, 52W range, market cap
- Final weighted score (0–100) with color band
- Baseline refresh date + validity date

### KPI cards (top row)
- Quality score
- Valuation score
- Growth score
- Balance-sheet score
- Cash-flow score

### Core table (center)
Columns:
- Metric
- Company Value
- Market Baseline
- Poor / Average / Good ranges
- Class
- Weight
- Metric Score
- Weighted Points

### Bottom strip
- 3 bullet thesis summary:
  1) What is working
  2) What to watch
  3) What would change the view

---

## Page 2 — Performance + Financial Lens
**Purpose:** combine technical context and financial trend quality.

### Left side (charts)
- 3Y price + MA20/MA50/MA200
- 3Y relative drawdown
- RSI (14)
- Volume

### Right side (financial trend mini-panels)
- Revenue growth trend (last 8 quarters)
- Margin trend (gross/op/net)
- FCF trend
- Leverage trend (Net debt/EBITDA where available)

### Footer callouts
- Bull case trigger
- Bear case trigger
- Neutral/base case

---

## Page 3 — Methodology, Definitions, and Data Integrity
**Purpose:** explain model and maintain trust.

Sections:
1. Metric definitions and measurement periods
2. Market baseline methodology (US/AU/NZ universe, weekly refresh)
3. Scoring formula details
4. Data availability rules (no guessing; show N/A)
5. Acronym legend

Table columns:
- Metric
- What it means
- Period measured over
- Source field(s)
- Missing-data fallback rule
