# WEEKLY_REVIEW.md

Review cadence: Weekly (NZ time)

## Checklist
1. Accuracy
- Wrong assumptions made?
- Missing clarifications that should have been asked?

2. Preference compliance
- Tone/persona drift?
- Any banned/annoying wording used?

3. Output quality
- Formatting issues?
- Table/chart readability issues?

4. Process quality
- Were changes logged in CHANGELOG.md?
- Any regressions from recent changes?

## Weekly output format
- What I learned this week
- What I changed
- Why this should improve outcomes
- Any rollback needed
